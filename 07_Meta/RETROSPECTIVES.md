# Retrospectives

> Monthly, at the last check-in of the month. Fifteen minutes on top of the usual thirty.
>
> Newest first. Copy the template below.

---

## Template

```markdown
## YYYY-MM — Month N

**Weeks covered:** W__ to W__

### 1. What is converting?

From the trackers, not from memory. Which source, which opener, which seniority tier, which
company tier.

### 2. What produced nothing in four weeks?

Kill it or fix it. Four weeks of zero output is enough evidence to act on.

### 3. What changes in the repo?

Open the PRs during the retro, not "later".

| Change | File | Who | PR |
|---|---|---|---|
| | | | |

### 4. How is the crew working?

Honestly. Are the check-ins useful or performative? Is one person carrying the other? Is the
callout mechanism actually being used, or is everyone being polite?

### 5. Next month's focus

One thing each, from the "weak in the search" list in each PROFILE.md.
```
